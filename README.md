# Tsukumo (付喪神)

**Talk to your things.** Point your phone at a mug, a plant or a lamp and say "wake up". Muse Spark gives it a
personality from what it looks like, Muse Image draws one character sheet for it, SAM keeps the face stuck to the
object as you move, Muse Voice Transcribe hears you and it answers out loud. Wake two objects and they talk to
each other.

Meta Global AI Developer Hackathon 2026. Status: **spec only**. Product code starts Oct 26, 2026 (event start).
Without `MODEL_API_KEY` it runs local SAM 2.1 tracking with a built-in face in puppet mode (you type its lines),
clearly labelled, and shows "Setup required" for the Meta models.

Spec: [`specs/tsukumo.md`](../../specs/tsukumo.md) in the grokbot handoff folder.
